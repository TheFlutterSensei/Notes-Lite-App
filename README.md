### Notes Lite App

Build a Flutter notes app to create and view notes.
Learn local data handling, input forms, and list views.
Perfect practice for real productivity apps.

Steps to use the app:
1. Clone the repository
2. Run ```flutter pub get```
3. Run ```flutter run```
4. Create, view, and manage notes in the app

### Build Your Flutter Notes App
